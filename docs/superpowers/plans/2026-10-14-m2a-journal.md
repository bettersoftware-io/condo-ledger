# M2a Journal & Daybook Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Journal & Daybook screen on the simulators (entries by number, expandable into postings with the running balance, searched, paged, one selectable and deletable), five journal-entry wizards writing through the journal port, the entry kind in the seed, and the design's journal export as a second oracle.

**Architecture:** The domain gains the entry kind, a draft, a typed result, `validateEntry`, `canDeleteEntry` and `journalOf`; the journal port gains `addEntry` and `deleteEntry`, with the simulator numbering and stamping as the legacy store did. In `client-core` a books presenter feeds both the accounts and the journal presenters; a grid machine pages and expands; three wizard machines share one contract and call the presenter's `addEntry`. The client generalises `TreeGrid` with leading cells, adds five primitives (dialog, confirm, form field, selectable list, menu item) and the Journal screen with its wizards.

**Tech Stack:** TypeScript (Node 26 type stripping), RxJS + `@rx-state/core`, React 19 + React Compiler, Vite 8, Vitest, Testing Library, Playwright 1.63.0 (visual goldens), `lucide-react`.

**Spec:** `docs/superpowers/specs/2026-10-14-m2a-journal-design.md` (its parent: `docs/superpowers/specs/2026-10-11-app-v2-design.md`; the layer shapes: `2026-10-12-m1-accounts-slice-design.md`).

**Worktree:** `../condo-ledger-worktrees/m2a-journal`, branch `worktree-m2a-journal`, cut from `origin/main` at `d68cbb3` with `pnpm worktree`; the spec is its first commit (`bfd1438`). Every command below runs there. The dump and the design's exports are in the project's own checkout, not in the worktree: a step that needs them sets `LEGACY_DUMP_DIR=/Users/csx/workarea/dev/github.com/bettersoftware-io/condo-ledger/old/db` and `DESIGN_ORACLE_DIR=/Users/csx/workarea/dev/github.com/bettersoftware-io/condo-ledger/docs/design/web/v1/reports/pozzetto`.

**Deviations from the spec, and why.** (1) `PostingView` carries `key` beside `path`: the fixture needs the side-less scope key and the grid needs a React key, and `journalOf` has both in hand. (2) Which dialog is open is a small machine (`journalDialogMachine`), not the screen's `useState`: the goldens open a wizard through the seeding, which can only reach a machine's intent. (3) `WizardState` carries `touched` (true after the first edit) so "show the reason once the person has edited" is decided in core, on fake timers. (4) `createJournalSimulator(seed, clock = systemClock)`: the second argument defaults, so the accounts presenter's tests and the contract harnesses are unchanged. (5) The view-model hook is `useJournalEntries(): JournalEntryView[]`, in the shape of `useAccountsTree`, not a `{ entries }` record. (6) `TreeGridRowData.leading` and `tone` are optional: the Accounts and Ledger grids are untouched. (7) The local journal check proves a control row's posting at the account level (the account's path and the amounts), not the party: the accounts check pairs control rows by amount, so a label-to-key map cannot name a party either; the fixture still carries the full key, which the presenter's oracle test checks against the seed.

`support/clock.ts`:

```ts
/** Where the time comes from. A simulator stamps with it; the server has its own. */
export interface Clock {
  now: () => Date;
}

export const systemClock: Clock = {
  now: (): Date => {
    return new Date();
  },
};

/** A clock stopped at one moment: tests and goldens stamp the same thing every run. */
export function fixedClock(iso: string): Clock {
  const moment = new Date(iso).getTime();

  if (Number.isNaN(moment)) {
    throw new Error(`not a moment: ${iso}`);
  }

  return {
    now: (): Date => {
      return new Date(moment);
    },
  };
}
```

```ts
// The legacy app showed, and the UI shows, Rome wall-clock time. A fixed zone,
// so a stamp never depends on the machine that writes or reads it.
const ROME = new Intl.DateTimeFormat("en-GB", {
  timeZone: "Europe/Rome",
  hourCycle: "h23",
  year: "numeric",
  month: "2-digit",
  day: "2-digit",
  hour: "2-digit",
  minute: "2-digit",
  second: "2-digit",
});

/** The moment as "YYYY-MM-DDTHH:mm:ss" on the Rome clock: the form the seed's entries carry. */
export function romeTime(date: Date): string {
  const parts = new Map(
    ROME.formatToParts(date).map((part) => {
      return [part.type, part.value];
    }),
  );

  return `${parts.get("year")}-${parts.get("month")}-${parts.get("day")}T${parts.get("hour")}:${parts.get("minute")}:${parts.get("second")}`;
}
```

```ts
import type { Account } from "../entities/account.ts";
import { addCents, ZERO_CENTS } from "../entities/cents.ts";
import type { EntryDraft, Posting } from "../entities/journal.ts";
import { ok, type Result, rejected } from "../entities/result.ts";

/**
 * Whether a draft may be written to the period whose accounts are given. The
 * reasons are checked in this order, and the first one found is answered.
 */
export function validateEntry(draft: EntryDraft, accounts: Account[]): Result {
  if (draft.description.trim() === "") {
    return rejected("blank-description");
  }

  if (draft.postings.length === 0) {
    return rejected("no-postings");
  }

  const byId = new Map(
    accounts.map((account) => {
      return [account.id, account];
    }),
  );

  for (const posting of draft.postings) {
    const reason = lineReason(posting, byId);

    if (reason !== null) {
      return rejected(reason);
    }
  }

  const debit = draft.postings.reduce((sum, posting) => {
    return addCents(sum, posting.debit);
  }, ZERO_CENTS);
  const credit = draft.postings.reduce((sum, posting) => {
    return addCents(sum, posting.credit);
  }, ZERO_CENTS);

  return debit === credit ? ok() : rejected("unbalanced");
}

function lineReason(posting: Posting, byId: Map<string, Account>): string | null {
  const account = byId.get(posting.accountId);

  if (account === undefined) {
    return "unknown-account";
  }

  if (account.type === "grouping") {
    return "not-a-leaf";
  }

  if (posting.debit === 0 && posting.credit === 0) {
    return "empty-line";
  }

  if (posting.debit !== 0 && posting.credit !== 0) {
    return "both-sides";
  }

  if (posting.debit < 0 || posting.credit < 0) {
    return "negative";
  }

  const control = account.type === "control" || account.type === "controlUnitResident";

  if (control && posting.counterpart === null) {
    return "counterpart-required";
  }

  if (!control && posting.counterpart !== null) {
    return "counterpart-not-allowed";
  }

  return null;
}
```

```ts
/** The Journal screen's data for one period: every entry by number, each posting with its row's path and the running balance. */
export function journalOf(
  root: AccountNode,
  entries: JournalEntry[],
): JournalEntryView[] {
  const rows = rowsOf(root);

  return entries
    .slice()
    .sort((a, b) => {
      return a.number - b.number;
    })
    .map((entry) => {
      let balance = ZERO_CENTS;
      let debit = ZERO_CENTS;
      let credit = ZERO_CENTS;
      const postings = entry.postings.map((posting) => {
        const row = rowOf(rows, posting);
        balance = subtractCents(addCents(balance, posting.debit), posting.credit);
        debit = addCents(debit, posting.debit);
        credit = addCents(credit, posting.credit);

        return {
          key: row.key,
          path: row.path,
          debit: posting.debit,
          credit: posting.credit,
          balance,
        };
      });

      return {
        id: entry.id,
        number: entry.number,
        at: entry.at,
        kind: entry.kind,
        description: entry.description,
        debit,
        credit,
        postings,
      };
    });
}

function rowOf(rows: Row[], posting: Posting): Row {
  const row = rows.find((candidate) => {
    return scopeOwns(candidate.scope, posting);
  });

  if (row === undefined) {
    throw new Error(`missing: the node of the posting on ${posting.accountId}`);
  }

  return row;
}

/** Every row of the tree that owns postings, with its path; a control row's trail skips the side level. */
function rowsOf(root: AccountNode): Row[] {
  const rows: Row[] = [];

  function walk(node: AccountNode, trail: AccountNode[]): void {
    const here = [...trail, node];

    if (node.scope !== null) {
      rows.push({ scope: node.scope, key: keyOf(node.scope), path: pathOf(here, node.scope) });
    }

    for (const child of node.children) {
      walk(child, here);
    }
  }

  walk(root, []);

  return rows;
}

function pathOf(trail: AccountNode[], scope: PostingScope): string {
  const kept =
    scope.kind === "account"
      ? trail
      : trail.filter((node) => {
          return !SIDE_KEYS.has(node.key);
        });

  return kept
    .map((node) => {
      return node.label;
    })
    .join(PATH_SEPARATOR);
}
```

```ts
  entries$: BehaviorSubject<JournalEntry[]>;
  accounts: Account[];
}

/**
 * The seed's journal, a period at a time, with what the wizards write kept in
 * memory. Numbers and stamps as the legacy store did: the next number of the
 * period, the clock's moment on the Rome wall clock; a delete moves every later
 * entry down one number. Throws on an unknown id: it never answers empty for
 * a wrong key.
 */
export function createJournalSimulator(
  seed: LegacySeed,
  clock: Clock = systemClock,
): JournalPort {
  const periods = new Map<string, PeriodJournal>();
  let added = 0;

  for (const building of seed.buildings) {
    for (const period of building.periods) {
      periods.set(period.id, {
        entries$: new BehaviorSubject(
          seed.entries
            .filter((entry) => {
              return entry.periodId === period.id;
            })
            .sort((a, b) => {
              return a.number - b.number;
            }),
        ),
        accounts: seed.accounts.filter((account) => {
          return account.periodId === period.id;
        }),
      });
    }
  }

  function journalOf(periodId: string): PeriodJournal {
    return must(periods.get(periodId), `the period ${periodId}`);
  }

  return {
    entries: (periodId: string): Observable<JournalEntry[]> => {
      const journal = periods.get(periodId);

      return journal === undefined
        ? throwError(() => {
            return new Error(`missing: the period ${periodId}`);
          })
        : journal.entries$.asObservable();
    },
    addEntry: (periodId: string, draft: EntryDraft): Promise<ResultOf<{ id: string }>> => {
      // A throw inside the executor is a rejection, as the port promises.
      return new Promise((resolve) => {
        const journal = journalOf(periodId);
        const verdict = validateEntry(draft, journal.accounts);

        if (!verdict.ok) {
          resolve(verdict);

          return;
        }

        const entries = journal.entries$.getValue();
        added += 1;
        const id = `new${added}`;

        journal.entries$.next([
          ...entries,
          {
            id,
            periodId,
            number: nextNumber(entries),
            at: romeTime(clock.now()),
            kind: draft.kind,
            description: draft.description,
            postings: draft.postings,
          },
        ]);
        resolve(accepted({ id }));
      });
    },
    deleteEntry: (entryId: string): Promise<Result> => {
      return new Promise((resolve) => {
        const journal = must(
          [...periods.values()].find((candidate) => {
            return candidate.entries$.getValue().some((entry) => {
              return entry.id === entryId;
            });
          }),
          `the entry ${entryId}`,
        );
        const entries = journal.entries$.getValue();
        const entry = must(
          entries.find((candidate) => {
            return candidate.id === entryId;
          }),
          `the entry ${entryId}`,
        );
        const verdict = canDeleteEntry(entry);

        if (verdict.ok) {
          journal.entries$.next(
            entries
              .filter((candidate) => {
                return candidate.id !== entryId;
              })
              .map((candidate) => {
                return candidate.number > entry.number
                  ? { ...candidate, number: candidate.number - 1 }
                  : candidate;
              }),
          );
        }

        resolve(verdict);
      });
    },
  };
}

/** The legacy rule: MAX(code) + 1 within the period, 1 in an empty one. */
function nextNumber(entries: JournalEntry[]): number {
  return entries.reduce((max, entry) => {
    return Math.max(max, entry.number);
  }, 0) + 1;
}
```

```ts
import { type DefaultedStateObservable, state } from "@rx-state/core";
import { combineLatest, map, type Observable } from "rxjs";

import { type Building, type EntryDraft, type JournalEntryView, type JournalPort, journalOf, rejected, type Result, type ResultOf } from "@cl/domain";

import type { Books } from "./booksPresenter.ts";
import type { PeriodSelection } from "./buildingsPresenter.ts";

/** What every wizard shows first: the building and the period the entry goes to. */
export interface JournalContext {
  building: string;
  period: string;
}

export interface JournalPresenter {
  entries$: DefaultedStateObservable<JournalEntryView[]>;
  context$: DefaultedStateObservable<JournalContext | null>;
  /** On the selected period; refused with `no-period` when none is. */
  addEntry: (draft: EntryDraft) => Promise<ResultOf<{ id: string }>>;
  deleteEntry: (id: string) => Promise<Result>;
}

/** The Journal screen: the selected period's entries as the grid shows them, and the two commands on it. */
export function createJournalPresenter(
  books$: Observable<Books | null>,
  buildings$: Observable<Building[]>,
  selected$: Observable<PeriodSelection | null>,
  port: JournalPort,
): JournalPresenter {
  let current: PeriodSelection | null = null;

  // The presenter lives as long as the application: nothing disposes it.
  selected$.subscribe((selection) => {
    current = selection;
  });

  return {
    entries$: state(
      books$.pipe(
        map((books) => {
          return books === null ? [] : journalOf(books.tree, books.entries);
        }),
      ),
      [],
    ),
    context$: state(
      combineLatest([buildings$, selected$]).pipe(
        map(([buildings, selection]) => {
          return contextOf(buildings, selection);
        }),
      ),
      null,
    ),
    addEntry: (draft: EntryDraft): Promise<ResultOf<{ id: string }>> => {
      return current === null
        ? Promise.resolve(rejected("no-period"))
        : port.addEntry(current.periodId, draft);
    },
    deleteEntry: (id: string): Promise<Result> => {
      return port.deleteEntry(id);
    },
  };
}

function contextOf(buildings: Building[], selection: PeriodSelection | null): JournalContext | null {
  if (selection === null) {
    return null;
  }

  for (const building of buildings) {
    for (const period of building.periods) {
      if (period.id === selection.periodId) {
        return { building: building.name, period: period.name };
      }
    }
  }

  return null;
}
```

```ts
import { type DefaultedStateObservable, state } from "@rx-state/core";
import { BehaviorSubject, combineLatest, map, type Observable } from "rxjs";

import type { JournalEntryView, PostingView } from "@cl/domain";

import type { Machine } from "./machine.ts";

export type PageSize = 10 | 25 | 50 | 100;

export const PAGE_SIZES: readonly PageSize[] = [10, 25, 50, 100];

export type JournalGridRow =
  | { kind: "entry"; entry: JournalEntryView; expanded: boolean; selected: boolean }
  | { kind: "posting"; entryId: string; index: number; posting: PostingView; last: boolean };

export interface JournalGridState {
  rows: JournalGridRow[];
  selectedId: string | null;
  expanded: string[];
  search: string;
  page: number;
  pageSize: PageSize;
  pageCount: number;
  /** The entries after the search. */
  total: number;
}

export interface JournalGridIntents {
  select: (id: string) => void;
  toggle: (id: string) => void;
  expandAll: () => void;
  collapseAll: () => void;
  setSearch: (text: string) => void;
  setPage: (page: number) => void;
  setPageSize: (size: PageSize) => void;
  /** The page that holds the entry, selected: what a saved entry gets. Unknown ids change nothing. */
  reveal: (id: string) => void;
}

interface Preferences {
  selectedId: string | null;
  expanded: ReadonlySet<string>;
  search: string;
  page: number;
  pageSize: PageSize;
}

const INITIAL: Preferences = { selectedId: null, expanded: new Set(), search: "", page: 1, pageSize: 10 };

/**
 * What the Journal grid shows of the presenter's entries: the page, the open
 * entries, the search and the selection. One per grid on screen. The state is
 * reconciled with the entries on every emission: a selected or open entry
 * that is gone is dropped, a page past the end becomes the last.
 */
export function createJournalGridMachine(
  entries$: Observable<JournalEntryView[]>,
): Machine<JournalGridState, JournalGridIntents> {
  const preferences$ = new BehaviorSubject<Preferences>(INITIAL);
  const latest = new BehaviorSubject<JournalEntryView[]>([]);
  const state$: DefaultedStateObservable<JournalGridState> = state(
    combineLatest([entries$, preferences$]).pipe(
      map(([entries, preferences]) => {
        latest.next(entries);

        return stateOf(entries, preferences);
      }),
    ),
    stateOf([], INITIAL),
  );
  const subscription = state$.subscribe();

  function update(change: Partial<Preferences>): void {
    preferences$.next({ ...preferences$.getValue(), ...change });
  }

  function visible(): JournalEntryView[] {
    return matching(latest.getValue(), preferences$.getValue().search);
  }

  return {
    state$,
    intents: {
      select: (id: string): void => {
        update({ selectedId: id });
      },
      toggle: (id: string): void => {
        const expanded = new Set(preferences$.getValue().expanded);

        if (!expanded.delete(id)) {
          expanded.add(id);
        }

        update({ expanded });
      },
      expandAll: (): void => {
        update({ expanded: new Set(visible().map(idOf)) });
      },
      collapseAll: (): void => {
        update({ expanded: new Set() });
      },
      setSearch: (text: string): void => {
        update({ search: text, page: 1 });
      },
      setPage: (page: number): void => {
        update({ page });
      },
      setPageSize: (size: PageSize): void => {
        update({ pageSize: size, page: 1 });
      },
      reveal: (id: string): void => {
        const index = visible().findIndex((entry) => {
          return entry.id === id;
        });

        if (index === -1) {
          return;
        }

        update({ selectedId: id, page: Math.floor(index / preferences$.getValue().pageSize) + 1 });
      },
    },
    dispose: (): void => {
      subscription.unsubscribe();
      preferences$.complete();
    },
  };
}

function stateOf(entries: JournalEntryView[], preferences: Preferences): JournalGridState {
  const found = matching(entries, preferences.search);
  const ids = new Set(found.map(idOf));
  const pageCount = Math.max(1, Math.ceil(found.length / preferences.pageSize));
  const page = Math.min(Math.max(1, preferences.page), pageCount);
  const expanded = [...preferences.expanded].filter((id) => {
    return ids.has(id);
  });
  const selectedId = preferences.selectedId !== null && ids.has(preferences.selectedId) ? preferences.selectedId : null;
  const open = new Set(expanded);
  const rows = found
    .slice((page - 1) * preferences.pageSize, page * preferences.pageSize)
    .flatMap((entry): JournalGridRow[] => {
      const isOpen = open.has(entry.id);
      const row: JournalGridRow = { kind: "entry", entry, expanded: isOpen, selected: entry.id === selectedId };

      if (!isOpen) {
        return [row];
      }

      return [
        row,
        ...entry.postings.map((posting, index): JournalGridRow => {
          return { kind: "posting", entryId: entry.id, index, posting, last: index === entry.postings.length - 1 };
        }),
      ];
    });

  return { rows, selectedId, expanded, search: preferences.search, page, pageSize: preferences.pageSize, pageCount, total: found.length };
}

/** The entries whose description holds the text, or whose number is the text; every entry for a blank search. */
function matching(entries: JournalEntryView[], search: string): JournalEntryView[] {
  const needle = search.trim().toLocaleLowerCase("it");

  if (needle === "") {
    return entries;
  }

  return entries.filter((entry) => {
    return String(entry.number) === needle || entry.description.toLocaleLowerCase("it").includes(needle);
  });
}

function idOf(entry: JournalEntryView): string {
  return entry.id;
}
```

```ts
import { type DefaultedStateObservable, state } from "@rx-state/core";
import { BehaviorSubject, map } from "rxjs";

import { type Cents, type EntryDraft, rejected, type Result, type ResultOf } from "@cl/domain";

import type { Machine } from "../machine.ts";

export interface PreviewLine { path: string; debit: Cents; credit: Cents; }

/** An account, or a row of the tree, the person may pick; grouped for the picker. */
export interface WizardChoice { key: string; label: string; group: string; }

export interface WizardState<TForm> {
  step: number;
  stepCount: number;
  form: TForm;
  choices: WizardChoice[];
  /** The "Entry postings" grid. */
  preview: PreviewLine[];
  /** validateEntry on the draft as it stands, after the wizard's own rules: decides Next and Save. */
  verdict: Result;
  /** True after the first edit: the UI shows the reason from then on. */
  touched: boolean;
  saving: boolean;
}

export interface WizardIntents<TForm> {
  edit: (patch: Partial<TForm>) => void;
  next: () => void;
  back: () => void;
  /** The draft to addEntry; Rejected with the verdict's reason, or `saving`, without calling it. */
  save: () => Promise<ResultOf<{ id: string }>>;
}

export type WizardMachine<TForm> = Machine<WizardState<TForm>, WizardIntents<TForm>>;

export type AddEntry = (draft: EntryDraft) => Promise<ResultOf<{ id: string }>>;

/** What a form derives: the preview, the verdict, and the draft when the verdict accepts. */
export interface Derived {
  preview: PreviewLine[];
  verdict: Result;
  draft: EntryDraft | null;
}

export interface WizardDefinition<TForm> {
  initial: TForm;
  stepCount: number;
  choices: WizardChoice[];
  derive: (form: TForm) => Derived;
}

interface Inner<TForm> { form: TForm; step: number; touched: boolean; saving: boolean; }

/** One contract for every wizard: the definition says what the form derives; the machine holds the form, the step and the save. */
export function createWizardMachine<TForm>(definition: WizardDefinition<TForm>, addEntry: AddEntry): WizardMachine<TForm> {
  const inner$ = new BehaviorSubject<Inner<TForm>>({ form: definition.initial, step: 1, touched: false, saving: false });
  const state$: DefaultedStateObservable<WizardState<TForm>> = state(
    inner$.pipe(
      map((inner) => {
        return stateOf(definition, inner);
      }),
    ),
    stateOf(definition, inner$.getValue()),
  );
  const subscription = state$.subscribe();

  function update(change: Partial<Inner<TForm>>): void {
    inner$.next({ ...inner$.getValue(), ...change });
  }

  return {
    state$,
    intents: {
      edit: (patch: Partial<TForm>): void => {
        update({ form: { ...inner$.getValue().form, ...patch }, touched: true });
      },
      next: (): void => {
        update({ step: Math.min(definition.stepCount, inner$.getValue().step + 1) });
      },
      back: (): void => {
        update({ step: Math.max(1, inner$.getValue().step - 1) });
      },
      save: async (): Promise<ResultOf<{ id: string }>> => {
        if (inner$.getValue().saving) {
          return rejected("saving");
        }

        const { verdict, draft } = definition.derive(inner$.getValue().form);

        if (!verdict.ok || draft === null) {
          return verdict.ok ? rejected("no-draft") : verdict;
        }

        update({ saving: true });

        try {
          return await addEntry(draft);
        } finally {
          update({ saving: false });
        }
      },
    },
    dispose: (): void => {
      subscription.unsubscribe();
      inner$.complete();
    },
  };
}

function stateOf<TForm>(definition: WizardDefinition<TForm>, inner: Inner<TForm>): WizardState<TForm> {
  const { preview, verdict } = definition.derive(inner.form);

  return { step: inner.step, stepCount: definition.stepCount, form: inner.form, choices: definition.choices, preview, verdict, touched: inner.touched, saving: inner.saving };
}
```

```ts
import { type Account, cents, type EntryDraft, ok, pathOf, rejected, type Result, validateEntry } from "@cl/domain";

import { parseAmount } from "../../amounts.ts";
import type { Books } from "../../presenters/booksPresenter.ts";
import { leafChoices, roleAccount } from "./choices.ts";
import { type AddEntry, createWizardMachine, type Derived, type WizardMachine } from "./wizard.ts";

export type DirectPaymentKind = "directPaymentCash" | "directPaymentBank" | "withholdingPayment";

export interface DirectPaymentForm {
  description: string;
  targetId: string | null;
  amount: string;
}

export const DIRECT_PAYMENT_DESCRIPTIONS: Record<DirectPaymentKind, string> = {
  directPaymentCash: "Direct cash purchase",
  directPaymentBank: "Direct purchase via bank account",
  withholdingPayment: "Withholding payment",
};

/** One target leaf debited, the cash or bank account credited: the three one-step wizards of the design. */
export function createDirectPaymentWizard(kind: DirectPaymentKind, books: Books | null, addEntry: AddEntry): WizardMachine<DirectPaymentForm> {
  const paidFrom = books === null ? null : roleAccount(books, kind === "directPaymentCash" ? "cash" : "bank");
  const choices = books === null ? [] : leafChoices(books, kind === "withholdingPayment" ? isTaxLeaf : isExpenseLeaf);

  return createWizardMachine(
    {
      initial: { description: DIRECT_PAYMENT_DESCRIPTIONS[kind], targetId: null, amount: "" },
      stepCount: 1,
      choices,
      derive: (form: DirectPaymentForm): Derived => {
        return derive(kind, books, paidFrom, form);
      },
    },
    addEntry,
  );
}

function derive(kind: DirectPaymentKind, books: Books | null, paidFrom: Account | null, form: DirectPaymentForm): Derived {
  if (books === null || paidFrom === null) {
    return refused("no-paid-from-account");
  }

  if (form.targetId === null) {
    return refused("no-target");
  }

  const amount = parseAmount(form.amount);

  if (amount === null) {
    return refused("not-an-amount");
  }

  const draft: EntryDraft = {
    kind,
    description: form.description,
    postings: [
      { accountId: form.targetId, debit: amount, credit: cents(0), counterpart: null },
      { accountId: paidFrom.id, debit: cents(0), credit: amount, counterpart: null },
    ],
  };
  const verdict = validateEntry(draft, books.accounts);
  const preview = [
    { path: shortPath(books, form.targetId), debit: amount, credit: cents(0) },
    { path: shortPath(books, paidFrom.id), debit: cents(0), credit: amount },
  ];

  return { preview, verdict, draft: verdict.ok ? draft : null };
}

function refused(reason: string): Derived {
  return { preview: [], verdict: rejected(reason), draft: null };
}

function isExpenseLeaf(account: Account): boolean {
  return account.nature === "expenses";
}

function isTaxLeaf(account: Account): boolean {
  return account.role === "tax";
}
```
